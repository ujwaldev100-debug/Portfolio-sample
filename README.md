# Sample Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Vite.

## Features

- Responsive portfolio layout
- About, education, experience, skills, and projects sections
- Modern UI and animations
- Optimized production build using Vite

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

## Project Structure

- `src/` — application source code
- `public/` — static assets
- `CERTIFICATIONS/` — certification documents
- `scripts/` — project scripts
